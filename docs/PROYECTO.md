# Proyecto de prueba de portabilidad

Dominio: tareas genéricas. Actor: usuario que registra una tarea. Regla: el título se recorta, espacios consecutivos se reducen y quedan al menos tres caracteres. Módulo independiente de Ecclesia. No hay cuenta, pagos ni datos personales. Este proyecto comprueba instalación y controles del arnés; no es un producto final.
